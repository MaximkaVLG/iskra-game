# Искра — приключение в логике

Питомец Искра: дом, кормление, мячик, дружба и украшения. Три короткие истории с логическими механизмами и наградами. 24 учебных урока, таблицы истинности и преобразования формул. Арена: пять кубков, десять задач за гонку, игровые соперники и вызов другу по ссылке.

Статическая игра, без аккаунта и сервера. Прогресс сохраняется в браузере. Шрифты Manrope и STIX Two Math: SIL Open Font License, см. assets/Manrope-LICENSE.txt и assets/STIXTwoMath-LICENSE.txt.
