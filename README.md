# Искра — приключение в логике

24 урока с дракончиком, таблицами истинности и преобразованиями формул. Арена: пять кубков, десять задач за гонку, игровые соперники и вызов другу по ссылке.

Статическая игра, без аккаунта и сервера. Прогресс сохраняется в браузере. Шрифты Manrope и STIX Two Math: SIL Open Font License, см. assets/Manrope-LICENSE.txt и assets/STIXTwoMath-LICENSE.txt.
